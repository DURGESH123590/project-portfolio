# 🚀 Durgesh Girde — Minimalist Portfolio

A professional, minimalist portfolio website building with React, Vite, Tailwind CSS, and Framer Motion. This project showcases my skills, projects, and professional background as a Full Stack Developer.

## ✨ Features

- **Modern Tech Stack**: Built with React 18, Vite, and Tailwind CSS.
- **Responsive Design**: Fully optimized for mobile, tablet, and desktop screens.
- **Animations**: Smooth transitions and scroll-reveal effects using Framer Motion.
- **Lazy Loading**: Optimized performance with React Concurrent Mode and Code Splitting.
- **Zero Backend**: Contact form powered by Netlify Forms.
- **Minimalist Aesthetic**: Clean, dark-themed UI focused on content.

## 🛠️ Tech Stack

- **Frontend**: React, Tailwind CSS, Framer Motion
- **Icons**: React Icons
- **Build Tool**: Vite
- **Deployment**: Netlify

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or above)
- `npm` (comes with Node.js)

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/durgeshgirde/durgesh-portfolio.git
   cd durgesh-portfolio
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```

## 📂 Project Structure

```text
src/
├── assets/      # Static assets (images, projects)
├── components/  # Reusable UI components
├── data/        # Centralized portfolio content
├── App.jsx      # Main application logic
├── main.jsx     # Entry point
└── index.css    # Global styles & Tailwind config
```

## 🌐 Deployment

### Netlify CLI (Recommended)

1. Initial login:
   ```bash
   netlify login
   ```

2. Deploy:
   ```bash
   npm run build
   ```
   ```bash
   netlify deploy --prod
   ```
